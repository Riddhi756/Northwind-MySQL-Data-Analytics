# MySQL Data Analytics Practice Project

## About the Project

This repository contains my MySQL practice project using the
Northwind dataset.

The main goal of this project is to practice SQL concepts used
for data analysis and strengthen my ability to solve practical
data-related problems using MySQL.

The queries in this project are written and practiced using
the Northwind database.

## Dataset

This project uses the **Northwind dataset**.

The database contains tables related to:

- Customers
- Orders
- Products
- Categories
- Suppliers
- Employees
- Shippers
- Order Details
- Territories
- Region

The database is not included in this repository. The SQL files
contain the queries used for practicing and analyzing the data.
